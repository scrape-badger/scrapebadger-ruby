# ScrapeBadger::GitHubApi

All URIs are relative to *https://scrapebadger.com*

| Method | HTTP request | Description |
| ------ | ------------ | ----------- |
| [**github_get_profile**](GitHubApi.md#github_get_profile) | **GET** /v1/github/profiles/{username} | Get profile |
| [**github_get_repository**](GitHubApi.md#github_get_repository) | **GET** /v1/github/repositories/{owner}/{repo} | Get repository |


## github_get_profile

> <GitHubProfileResponse> github_get_profile(username, opts)

Get profile

Public user or organization profile, pins/popular repositories, README and contributions.  The overview preserves GitHub's public website sections, including organization-specific metadata. Compact displayed counts are approximate and marked with *_approximate. Unavailable or blocked data is an unbilled error, never an empty success.

### Examples

```ruby
require 'time'
require 'scrapebadger'
# setup authorization
ScrapeBadger.configure do |config|
  # Configure API key authorization: ApiKeyAuth
  config.api_key['X-API-Key'] = 'YOUR API KEY'
  # Uncomment the following line to set a prefix for the API key, e.g. 'Bearer' (defaults to nil)
  # config.api_key_prefix['X-API-Key'] = 'Bearer'
end

api_instance = ScrapeBadger::GitHubApi.new
username = 'username_example' # String | 
opts = {
  tab: 'overview', # String | Profile section; stars is available for users only
  year: 56, # Integer | Overview only: 1970 through the current UTC year; activity is December or current month
  page: 56, # Integer | Repositories only: page number, 30 rows per page
  next_page_token: 'next_page_token_example', # String | Stars only: previous pagination.next_page_token
  prefer: 'respond-async, wait=25', # String | `respond-async[, wait=N]` (RFC 7240): run the call async. If it has not finished after `wait` seconds (0-120, default 25) the answer is `202` with a `request_id`; poll `GET /v1/requests/{request_id}`. Its `wait=` wins over `async_wait`; without one, `async_wait` sets the wait.
  x_callback_url: 'x_callback_url_example', # String | An `https` URL that receives the signed `request.completed` webhook when the call finishes. Implies async: on its own (no `Prefer`, `async` or `async_wait`) the answer is an immediate `202`; with `Prefer: respond-async` or `async=true` the call still waits 25 s unless a wait is given. Wins over `callback_url`.
  idempotency_key: 'idempotency_key_example', # String | 1-200 visible ASCII characters, per account, kept as long as the result (about 15 minutes). The same key on the same call returns that call's current state (`Idempotent-Replayed: true`) without running or billing it again; on a different call it is `409 idempotency_key_reused`. Applies to async calls only; on a synchronous call it is ignored. Wins over `idempotency_key`.
  async: true, # Boolean | Query form of `Prefer: respond-async`: `true` or `1` (also `yes`, `on`; `false`, `0`, `no`, `off` leave the call synchronous). Waits 25 s unless `async_wait` is given. Not sent to the scraper.
  async_wait: 56, # Integer | Seconds (0-120; values outside are clamped) to wait for the result before answering `202`. Implies async. Not sent to the scraper.
  callback_url: 'callback_url_example', # String | Query form of `X-Callback-URL` (URL-encode it). Implies async; on its own the answer is an immediate `202` (wait 0). Not sent to the scraper.
  idempotency_key2: 'idempotency_key_example' # String | Query form of `Idempotency-Key`. Not sent to the scraper.
}

begin
  # Get profile
  result = api_instance.github_get_profile(username, opts)
  p result
rescue ScrapeBadger::ApiError => e
  puts "Error when calling GitHubApi->github_get_profile: #{e}"
end
```

#### Using the github_get_profile_with_http_info variant

This returns an Array which contains the response data, status code and headers.

> <Array(<GitHubProfileResponse>, Integer, Hash)> github_get_profile_with_http_info(username, opts)

```ruby
begin
  # Get profile
  data, status_code, headers = api_instance.github_get_profile_with_http_info(username, opts)
  p status_code # => 2xx
  p headers # => { ... }
  p data # => <GitHubProfileResponse>
rescue ScrapeBadger::ApiError => e
  puts "Error when calling GitHubApi->github_get_profile_with_http_info: #{e}"
end
```

## github_get_repository

> <GitHubRepositoryResponse> github_get_repository(owner, repo, opts)

Get repository

Public default-branch repository detail, native README, files and latest commit.  Use owner.login and name from a profile repository summary. Root file and contributor previews are not exhaustive recursive trees or membership lists. No GitHub token, market, ref, search or pagination parameter is accepted.
